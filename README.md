# Digit Nepal Website

Company website built with Next.js, React, Tailwind CSS, and Framer Motion. The billing workspace has moved to the separate [finance-digitnepal](https://github.com/ialekhc/finance-digitnepal) project.

## Local development

Use Node.js 24+ and npm 10+. Run `npm ci` and `npm run dev`; the site opens at `http://localhost:3000`. Run `npm run build` to verify the production website.

## Deployment

Deploy this repository to Vercel using the root `vercel.json`. The public website is served at `digitnepal.com`. Billing is deployed separately at `finance.digitnepal.com`.
